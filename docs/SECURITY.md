# Security Model

## MVP

第一版只对用户输入进行界面演示和示例分析，不克隆仓库、不执行上传文件、不运行用户命令。

## 后续执行 Worker 要求

- API 和 Sandbox Worker 分离部署
- 非 root 用户和只读文件系统
- 默认关闭网络
- 不向任务容器注入任何服务密钥
- CPU、内存、磁盘、进程数和运行时间限制
- 临时工作区，结束后强制销毁
- 命令、网络和算力使用必须人工审批
- 不挂载 Docker Socket 或宿主机目录
- 所有动作生成不可变 Run ID 和审计日志

## 数据

- 生产环境不得把用户论文提交到 Git 仓库
- 上传文件设置自动过期时间
- 日志不得记录 API Key、Cookie 或完整用户路径
- 示例数据必须拥有再分发权限或只保存公开链接与元数据
