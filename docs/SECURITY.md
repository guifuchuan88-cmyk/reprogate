# Security Model

## v0.3

- 只读取用户主动提交的公开 GitHub 仓库。
- 不克隆仓库，不执行仓库代码、脚本或命令。
- PDF 只通过 Web Crypto 在本机计算 SHA-256；正文不上传、不保存、不解析。
- 分析结果只保留在当前页面内，导出必须由用户主动触发。
- 所有外部文本在渲染前进行 HTML 转义，来源链接只允许 HTTPS。
- 实时请求失败时不自动替换为样例数据，防止把演示结果误认为真实结果。
- GitHub 匿名 API 可能限流；v0.3 不要求用户在前端粘贴 Token。
- 金融公式以结构化数据表示，只允许六种固定二元运算；不使用 `eval`、动态函数或任意代码字符串。
- 公式执行限制嵌套深度和节点数，并拒绝零分母、未知引用、非有限输入与非有限输出。
- 内置金融案例为深度冻结的原创合成 fixture；不包含真实投资建议、官方 benchmark 记录或完整财报。
- 金融证据、问题和公式字段继续逐字段 HTML 转义；外部方法链接继续只允许 HTTPS。

## 后续执行 Worker 要求

- API 和 Sandbox Worker 分离部署
- 非 root 用户和只读文件系统
- 默认关闭网络，按域名临时放行
- 不向任务容器注入服务密钥
- CPU、内存、磁盘、进程数和运行时间限制
- 临时工作区，任务结束后强制销毁
- 命令、网络和算力使用必须人工审批
- 不挂载 Docker Socket 或宿主机目录
- 所有动作生成不可变 Run ID 和审计日志

## 数据

- 用户论文不得提交到 Git 仓库
- 服务端上传文件必须加密并设置自动过期时间
- 日志不得记录 API Key、Cookie、完整用户路径或论文正文
- 样例数据必须明确标注且拥有再分发权限，或只保存公开链接与元数据
