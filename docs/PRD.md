# ReproGate v0.4 PRD

## 用户问题

学生和研究者通常在已经投入安装、下载和算力之后，才发现研究代码缺少锁文件、运行入口、资产版本或环境说明。失败发生得太晚，而且“不知道”经常被包装成一个过度自信的 AI 回答。

金融推理产品还有第二类问题：最终数值看起来合理，却无法判断错在财报检索、证据引用、单位量级、公式分母还是答案抄写。普通聊天界面隐藏了这条故障链。

## v0.4 目标用户

- 为课题选择 Baseline 的硕士生和博士生
- 评估开源项目质量的 AI 产品/研发实习候选人
- 进行 Artifact 初筛的研究者
- 评估金融 RAG、数值推理或 Agent 可靠性的产品与研发人员

## 核心体验 A：仓库审计

1. 输入公开 GitHub 仓库，可选附加本地 PDF 指纹。
2. 系统锁定 commit 并扫描元数据、文件树、README 与 manifests。
3. 确定性规则输出静态准备度、检查矩阵、证据和风险。
4. 用户导出 ReproSpec JSON 或最小验证任务单。
5. 实时失败不会静默降级为演示结果；演示快照始终标记为 SAMPLE。

## 核心体验 B：金融推理审计

1. 按 benchmark-inspired 评测范式标签或故障类型，从 5 个冻结的原创合成案例中筛选目标。
2. 查看问题、财报片段、页码、结构化事实与候选输出。
3. 浏览器安全执行白名单公式 AST，并保留逐步数值轨迹。
4. 分别判定证据、单位、分母和数值一致性，显示首要诊断。
5. 同屏对比冻结基线与参考答案回放，显示分数与相对故障 delta；不将参考对象描述为模型修复。
6. 复制当前 fixture 版本深链接，并显式保存浏览器本地对比快照。
7. 导出带能力边界的审计 JSON 或 Markdown 合成案例审计对比卡。

## 成功标准

- 首次使用者 60 秒内理解最高优先级风险。
- 100% 风险拥有文件路径或仓库元数据来源。
- 地址错误、404、限流、断网均有可恢复状态。
- 导出结果声明代码未执行、论文未解析、外部资产未验证。
- 规则引擎核心路径具备自动测试。
- 金融案例的所有公式输入都能解析到证据 registry。
- 非法运算、零分母、非有限值和未知事实 100% 显式失败。
- 冻结案例、真实扫描和官方 benchmark 记录的混淆率为 0。
- 分享链接刷新后恢复同一案例、候选与单项/对比视图。
- 浏览器本地快照最多 20 条，保存字段透明，且不包含完整证据原文或 PDF。

## 北极星与护栏

- 北极星：被用户采纳的“下一步验证任务/首要诊断”比例。
- 质量指标：Blocker Precision@5、证据链接有效率、故障分类准确率、静态分数校准误差。
- 护栏：真实/样例混淆率为 0；未经批准的代码执行为 0；论文正文上传为 0。

## 非目标

- 宣称已复现论文结论
- 通用论文问答或 Related Work 生成
- 自动运行任意 GitHub 仓库
- 从静态文本推断外链当前可用
- 在前端收集 GitHub Token
- 生成投资建议或真实公司财务结论
- 将单个合成案例的分数称为 benchmark 准确率
- 展示或伪造模型隐式 chain-of-thought
- 未确认许可证前重新分发 FinanceBench 数据或财报 PDF

## 后续验证

用 30–50 个研究仓库建立人工标注集，将 README-only、通用 LLM 审阅和 ReproGate 对比。指标包括 blocker precision、首次命令成功率、time-to-first-smoke-test 和避免的无效 GPU 时间。

金融方向先使用原创合成 fixture 验证交互与错误分类；取得明确再分发授权后，再引入少量官方 case manifest。评测重点是证据覆盖、单位/分母错误召回、首要诊断准确率，以及用户能否在 60 秒内解释候选答案为什么被阻断。
